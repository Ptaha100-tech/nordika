# Как запустить «Nordika: сердце фьорда» на своём сервере

Всё по шагам. Если на каком-то шаге что-то идёт не так, пришлите мне, что видите на экране, и я подскажу.

## Что понадобится

1. **Сервер (VPS)**: арендованный компьютер в интернете, около 150–300 рублей в месяц. Нужно: **Ubuntu 24.04**, 1–2 ГБ памяти, расположение в России, оплата российской картой или СБП, «веб-консоль» (терминал прямо в браузере). Подойдёт Selectel, VDSina, Timeweb Cloud, Beget, Aeza. Цены меняются, смотрите на сайте.
2. **Аккаунт на GitHub** (бесплатно). Через него игра попадает на сервер и потом обновляется сама.
3. **Домен не обязателен.** Если адреса нет, скрипт сам возьмёт бесплатный вида `203-0-113-5.sslip.io`, и https будет работать. Своё красивое имя (например, nordika.ru) можно купить позже, это от 200 рублей в год.

## Шаг 1. Репозиторий на GitHub

1. На github.com нажмите «New» (новый репозиторий), назовите его `nordika`, выберите **Public** и создайте.
2. Напишите мне ваш логин на GitHub. Я загружу туда все файлы игры. В репозитории нет паролей и данных игроков, только код.

## Шаг 2. Создайте сервер

1. На сайте хостинга закажите сервер: система **Ubuntu 24.04**, самый дешёвый тариф с 1–2 ГБ памяти.
2. Запишите его **IP-адрес** и откройте веб-консоль (кнопка «Консоль»). Вы входите как root.

## Шаг 3. Установите игру

В консоли вставляйте по одной команде. Вместо `ВАШ_ЛОГИН` впишите логин GitHub.

```
apt-get update && apt-get install -y git
git clone https://github.com/ВАШ_ЛОГИН/nordika.git /opt/nordika-src
cd /opt/nordika-src
bash deploy/setup.sh
```

Если у вас есть свой домен, который уже указывает на IP сервера, добавьте его в конце последней команды: `bash deploy/setup.sh nordika.ru`.

Подождите 3–6 минут. В конце появится «Готово» и адрес игры. Откройте его в браузере телефона.

## Шаг 4. Играйте и ставьте на главный экран

1. «Новая игра»: имя и пароль.
2. Chrome на Android: меню «⋮» → «Установить приложение». Safari на iPhone: «Поделиться» → «На экран Домой».
3. Дайте ссылку друзьям. Все, кто зарегистрируется, окажутся на одной карте, смогут грабить друг друга и объединяться в кланы.

## Обновления игры

Сервер сам смотрит в GitHub каждые 3 минуты. Когда я загружаю новую версию, она появляется у игроков через 3–5 минут, прогресс игроков не пропадает. Руками ничего делать не надо.

## Что где лежит и как этим управлять

| Что | Где |
|---|---|
| Данные игроков и кланов | `/var/lib/nordika` |
| Ежедневные копии | `/var/backups/nordika` (хранятся 7 дней) |
| Журнал игры | `journalctl -u nordika -n 50` |
| Перезапуск игры | `systemctl restart nordika` |

**Темп игры.** Он задаётся числом `TIME_MUL`. Сейчас 10: первая стройка около 4 минут, высокие уровни занимают часы и сутки. Чтобы изменить, откройте файл `/etc/systemd/system/nordika.service`, поменяйте число в строке `Environment=TIME_MUL=10` и выполните `systemctl daemon-reload && systemctl restart nordika`. Чем число больше, тем игра медленнее.

## Если что-то не работает

- **Страница не открывается.** Подождите 5–10 минут и обновите. Затем в консоли выполните `systemctl status nginx` и `systemctl status nordika`, пришлите мне вывод.
- **Не выпустился сертификат https.** Скрипт напишет, какую команду выполнить позже. Чаще всего помогает подождать 10 минут.
- **Белый экран или ошибка 502.** Выполните `journalctl -u nordika -n 50` и пришлите мне вывод.
